## 🛠️ Installation & Setup

### Prerequisites
Ensure you have [Node.js](https://nodejs.org/) installed on your machine.

### Quick Start
1. **Clone the Repo**
   ```bash
   git clone https://github.com/TARUNprojectworks/Xtreme-Fitness.git
   ```
2. **Step into the Zone**
   ```bash
   cd Xtreme-Fitness
   ```
3. **Equip Dependencies**
   ```bash
   npm install
   ```
4. **Ignite the App**
   ```bash
   npm start
   ```
